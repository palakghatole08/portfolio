# Palak Ghatole Portfolio

A single-page, responsive portfolio inspired by the reference style at:
https://kumaresh-portfolio-wmdj.vercel.app/

## Included
- Dark ambient glassmorphism UI
- Responsive desktop/mobile navigation
- Animated hero section
- About section + terminal-style profile panel
- Skills cards based only on Palak's resume
- Three featured projects
- Education timeline
- NPTEL certifications
- Achievements / extracurricular section
- Contact section with LinkedIn/GitHub/email
- Theme toggle
- Small portfolio chatbot with preset answers
- No framework or build step required

## Run locally
Open `index.html` directly in a browser, or use any static server.

## Deploy on Vercel
1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`.
3. Import the repository into Vercel.
4. Framework preset: `Other` / no framework.
5. Build command: leave empty.
6. Output directory: leave empty / root.
